
# E-commerce UI Improvement

## 1. Giới thiệu
Trang web cải tiến giao diện thẻ sản phẩm (Product Card) cho website thương mại điện tử (Shopee UI).

## 2. Website tham khảo
- Tên website: Shopee
- URL: https://shopee.vn
- Khu vực đã khảo sát: Trang chủ, Danh mục, Chi tiết sản phẩm, Tìm kiếm, Giỏ hàng.

## 3. Chức năng
- Hiển thị danh sách sản phẩm dạng lưới (CSS Grid) co giãn linh hoạt (Responsive).
- Hiển thị rõ ràng tên, hình ảnh, giá khuyến mãi, giá gốc gạch ngang và tỷ lệ giảm giá.
- Nút thao tác mua hàng trực quan trực tiếp trên từng thẻ sản phẩm.

## 4. Công nghệ
- HTML5
- CSS3 (Flexbox & Grid)

## 5. Cách chạy
Mở file index.html bằng trình duyệt web (Google Chrome).

## 6. Cải tiến đã thực hiện
- Khắc phục tình trạng nhồi nhét thông tin trên thẻ sản phẩm gốc.
- Phân cấp lại màu sắc và bố cục giá tiền giúp người dùng dễ dàng so sánh giá.
